# Almanac

A personal daily-brief app for Android: today's and tomorrow's calendar
events, task lists with a start-of-day review, a morning reminder, and
two-way sync with Google Tasks so items added through Gemini show up in the
app.

Almanac is a personal project. It is not on an app store and has no user
accounts, servers, or advertising.
